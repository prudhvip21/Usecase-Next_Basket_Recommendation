# Next Basket Recommendation

Predict which products a grocery customer will buy in their next order.

## Approach

- Exploratory analysis in Python and Tableau on Instacart data
- TARS, FP-Growth and periodic FP-Growth pattern mining
- User-specific and category-level LightGBM models
- Ensembling of the approaches

## Results

The ensemble improved F1 score from 0.25 to 0.38.
